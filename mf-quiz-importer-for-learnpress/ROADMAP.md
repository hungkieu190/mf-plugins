# Quiz Importer for LearnPress Roadmap

## Product Review

The plugin currently imports LearnPress quizzes and questions from CSV, JSON, and XLSX files. It supports complete quiz imports, questions-only imports into an existing quiz, standard LearnPress question types, sample files, and an admin UI with progress feedback.

## Fixes To Prioritize

### 1. Remove Misleading XLS Support

The UI currently allows `.xls` uploads, but the parser returns an unsupported-format error for legacy XLS files. Either remove `.xls` from the accepted formats or add real XLS support through a parser library.

Recommended first step: remove `.xls` from UI copy, upload validation, and docs until true support exists.

### 2. Unify Question Import Logic For LearnPress 4

Complete quiz imports use LearnPress 4 database tables for answers and quiz-question relationships, but questions-only imports use older post meta keys such as `_lp_answer_options`, `_lp_answer`, and `_lp_questions`.

This can cause questions imported into existing quizzes to not behave consistently in LearnPress 4.

Recommended fix: make `MF_Question_Importer` reuse the same LearnPress 4 question creation and quiz attachment logic used by `MF_Quiz_Creator`.

### 3. Improve CSV Row Handling

The CSV import uses `array_combine($header, $row)`, which can fail or warn when a row has missing or extra columns.

Recommended fix: normalize each row to match the header length before combining, and report row-level validation errors.

### 4. Relax File MIME Validation

Some servers and browsers upload CSV/JSON files as `text/plain` or `application/octet-stream`. Current MIME checks may reject valid files.

Recommended fix: validate by extension first, then use MIME as a secondary signal.

### 5. Enforce License Checks On Import Actions

The plugin has a license system, but AJAX import actions currently only check user capability.

Recommended fix: block upload/import processing when the license is inactive, if this plugin is intended to be paid-gated.

## Feature Roadmap

### Version 1.0.1 - Stability And Compatibility

- Fix questions-only import for LearnPress 4.
- Remove misleading XLS support or implement real XLS support.
- Improve CSV row validation and error reporting.
- Improve file extension/MIME handling.
- Add license checks to import AJAX actions.

### Version 1.1.0 - Preview And Safer Imports

- Add Preview & Validate Before Import.
- Show parsed quiz/question count before import.
- Display row-level errors before committing data.
- Add Confirm Import step.
- Add detailed import report after completion.
- Include edit links for created quizzes/questions.
- Add downloadable CSV/JSON import report.

### Version 1.2.0 - Duplicate Handling And Quiz Metadata

- Add duplicate handling modes:
  - Skip existing quiz/question by title.
  - Update existing quiz/question.
  - Always create new.
  - Add suffix to duplicates.
- Add more question fields:
  - mark
  - hint
  - difficulty
  - category
  - tags
  - question_order
  - randomize_answers
- Add more quiz settings:
  - review answers
  - show correct answers
  - instant check
  - negative marking
  - pagination/questions per page
  - preview quiz
  - duration unit

### Version 1.3.0 - Course Attachment And Export

- Allow imports to attach quizzes directly to a course/section.
- Support `course_id`, `course_slug`, and `section_name` fields.
- Add export functionality for quizzes and questions.
- Export selected quizzes to JSON, CSV, and XLSX.
- Include answers, explanations, quiz settings, and question metadata in exports.

### Version 1.4.0 - Question Bank

- Add Question Bank mode.
- Import questions without attaching them to a quiz.
- Add filters for type, category, tag, difficulty, and source import.
- Select existing bank questions and add them to quizzes.
- Support bulk edit for question metadata.

### Version 1.5.0 - Media And AI Import

- Add media support for question content and answer options.
- Support remote image URLs.
- Optionally download media into WordPress Media Library.
- Add Paste AI Output import mode.
- Support JSON and Markdown generated by ChatGPT or similar tools.
- Add built-in prompt templates for generating LearnPress-compatible quiz files.

## Highest Value Next Updates

1. Fix questions-only import for LearnPress 4.
2. Add Preview & Validate Before Import.
3. Add Duplicate Handling.
4. Add Course/Section attachment.
5. Add Export Quiz functionality.
