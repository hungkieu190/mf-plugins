# Quiz Importer for LearnPress - Product Roadmap

Thư mục `planning/` là nơi lưu kế hoạch phát triển sản phẩm theo version.

Quy ước:

- `roadmap.md`: tầm nhìn tổng thể và thứ tự ưu tiên dài hạn.
- `version-*.md`: kế hoạch chi tiết cho từng version.
- Mỗi file version phải có checklist để AI/developer triển khai và đánh dấu sau khi hoàn thành.
- Khi một task được làm xong, người thực hiện phải đổi checklist từ `[ ]` sang `[x]` trong chính file kế hoạch.
- Không được đánh dấu `[x]` nếu chưa code xong, chưa kiểm tra, hoặc còn blocker chưa xử lý.

## Product Review

Plugin hiện tại import LearnPress quizzes và questions từ CSV, JSON, XLSX. Sản phẩm đã có admin UI, sample files, progress feedback, import quiz đầy đủ và import questions-only vào quiz có sẵn.

Các điểm cần củng cố trước khi thêm feature lớn:

- Import questions-only phải tương thích LearnPress 4 giống import quiz đầy đủ.
- UI/docs không được quảng cáo định dạng chưa hỗ trợ thật.
- CSV parser phải chịu được row thiếu/thừa cột và trả lỗi theo dòng.
- Upload validation phải linh hoạt với MIME trên nhiều hosting.
- License gate phải khóa cả UI lẫn AJAX backend actions.

## Version 1.0.1 - Stability And Compatibility

File kế hoạch chi tiết: `planning/version-1.0.1.md`

Mục tiêu:

- Sửa lỗi import questions-only trên LearnPress 4.
- Gỡ hỗ trợ `.xls` gây hiểu nhầm, chỉ giữ `.xlsx` cho Excel.
- Cải thiện CSV row validation và error reporting.
- Cải thiện file extension/MIME validation.
- Thêm license checks cho AJAX upload/import actions.

Đây là bản sửa lỗi nền tảng. Không thêm feature lớn trong version này.

## Version 1.1.0 - Preview And Safer Imports

Mục tiêu: giúp admin kiểm tra dữ liệu trước khi commit vào LearnPress.

- Add Preview & Validate Before Import.
- Show parsed quiz/question count before import.
- Display row-level errors before committing data.
- Add Confirm Import step.
- Add detailed import report after completion.
- Include edit links for created quizzes/questions.
- Add downloadable CSV/JSON import report.

## Version 1.2.0 - Duplicate Handling And Quiz Metadata

Mục tiêu: kiểm soát duplicate và import nhiều metadata hơn.

- Add duplicate handling modes:
  - Skip existing quiz/question by title.
  - Update existing quiz/question.
  - Always create new.
  - Add suffix to duplicates.
- Add more question fields:
  - `mark`
  - `hint`
  - `difficulty`
  - `category`
  - `tags`
  - `question_order`
  - `randomize_answers`
- Add more quiz settings:
  - review answers
  - show correct answers
  - instant check
  - negative marking
  - pagination/questions per page
  - preview quiz
  - duration unit

## Version 1.3.0 - Course Attachment And Export

Mục tiêu: import quiz vào course/section và thêm chiều export dữ liệu.

- Allow imports to attach quizzes directly to a course/section.
- Support `course_id`, `course_slug`, and `section_name` fields.
- Add export functionality for quizzes and questions.
- Export selected quizzes to JSON, CSV, and XLSX.
- Include answers, explanations, quiz settings, and question metadata in exports.

## Version 1.4.0 - Question Bank

Mục tiêu: tách import questions thành question bank để dùng lại nhiều quiz.

- Add Question Bank mode.
- Import questions without attaching them to a quiz.
- Add filters for type, category, tag, difficulty, and source import.
- Select existing bank questions and add them to quizzes.
- Support bulk edit for question metadata.

## Version 1.5.0 - Media And AI Import

Mục tiêu: hỗ trợ nội dung giàu media và dữ liệu từ AI.

- Add media support for question content and answer options.
- Support remote image URLs.
- Optionally download media into WordPress Media Library.
- Add Paste AI Output import mode.
- Support JSON and Markdown generated by ChatGPT or similar tools.
- Add built-in prompt templates for generating LearnPress-compatible quiz files.
